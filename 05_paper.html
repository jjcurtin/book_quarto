5  Writing a Paper

5.1 What a paper needs

A paper needs things a report doesn’t:

  • Citations and a reference list in a required style
  • Numbered figures and tables you can refer to in the text
  • An abstract
  • No visible code

And usually a Word file:

  • Co-authors edit it with track changes
  • Many journals ask for .docx

5.2 Start from your report

In the terminal, in your mendota_ice folder:

cp report.qmd paper.qmd
  • cp copies a file: first the original, then the new name
  • paper.qmd starts with everything your report has

Copying is fine for today, but now the same code lives in three files: report, slides, and paper.

  • Change one, and you must remember to change the other
  • The DRY unit shows how to keep the code in one place

5.3 A paper’s YAML header

Replace the YAML header at the top of paper.qmd:

---
title: "Ice Cover on Lake Mendota"
author: "Your Name"
date: today
abstract: |
  Lake Mendota freezes for fewer days each winter than it did in the 1800s.
  We summarize more than 170 years of ice records.
format: docx
execute:
  echo: false
---
  • abstract: | starts a block; the indented lines below it are the abstract
  • format: docx builds a Word document
  • execute: echo: false hides all code; readers see only the results
  • No embed-resources needed; a Word file always holds its own figures

5.4 Render to Word

quarto render paper.qmd

Quarto writes paper.docx next to your .qmd.

  • Open it in Word (or Google Docs, or LibreOffice)

You should see:

  • The abstract under the title
  • Your sections, sentences, and figure
  • No code

On Windows, close paper.docx in Word before you render again.

  • Word locks open files, so Quarto can’t replace it

5.5 Citations need a .bib file

You downloaded refs.bib during setup. It holds one entry (shortened here):

@dataset{magnuson2026,
  author    = {Magnuson, J. J. and Carpenter, S. R. and Stanley, E. H.},
  title     = {{North Temperate Lakes LTER}: Ice Duration - ...},
  year      = {2026},
  publisher = {Environmental Data Initiative},
  doi       = {10.6073/pasta/6a95bee73799927cbafbf87393be7038},
  ...
}
  • magnuson2026 is the citation key; you cite the source with it
  • Get entries from Google Scholar (Cite → BibTeX), a journal’s “Export citation” link, or Zotero

Point your paper to the file; add to the YAML header:

bibliography: refs.bib

5.6 Citation style

Quarto’s default style is Chicago author-date.

  • For APA, add one more line to the YAML header:
bibliography: refs.bib
csl: apa.csl

A CSL (Citation Style Language) file describes one style.

  • You downloaded apa.csl during setup, next to refs.bib
  • Thousands of styles, including many journals, are at https://www.zotero.org/styles
  • For another style, download its .csl file into your repo and change the csl: line

5.7 Cite a source

In your Background section, add a citation to the first sentence:

Lake Mendota has been watched for ice since the **1850s** [@magnuson2026].
You type Quarto writes
[@magnuson2026] (Magnuson et al., 2026)
@magnuson2026 Magnuson et al. (2026)

At the very end of paper.qmd, add a heading:

## References
  • Quarto puts the reference list there, formatted in APA

5.8 Number the figure

Change the figure chunk’s label and add a caption:

```{r}
#| label: fig-ice_days
#| fig-cap: "Days of ice cover on Lake Mendota, by winter."

ice |>
  ggplot(aes(x = year, y = ice_days)) +
  geom_line() +
  labs(x = "Winter (year it ended)", y = "Days of ice cover") +
  theme_minimal()
```

Then refer to it in a sentence:

Ice cover has declined since the 1850s (@fig-ice_days).
  • The label must start with fig-; Quarto requires that hyphen (the rest stays snake_case)
  • Quarto numbers the figure and writes “Figure 1” for you

5.9 Add a numbered table

Add a new chunk:

```{r}
#| label: tbl-periods
#| tbl-cap: "Ice cover by half century."

ice |>
  group_by(half_century = floor(year / 50) * 50) |>
  summarize(winters = n(), mean_days = round(mean(ice_days))) |>
  knitr::kable()
```

Then refer to it in a sentence:

@tbl-periods shows the average for each half century.
  • Same pattern as figures: a tbl- label, a tbl-cap caption
  • knitr::kable() turns a data frame into a table that works in Word, PDF, and HTML

ImportantTry it

  2. Cite @magnuson2026 in your Background section, and add ## References at the end
  3. Give your figure a fig- label and a caption, and refer to it in a sentence
  4. Add the table chunk, and refer to it in a sentence
  5. Render, and open paper.docx

5.11 Your turn: check your paper

In paper.docx, look for (Magnuson et al., 2026), Figure 1, Table 1, and the reference list.

A typo doesn’t stop the render.

  • Quarto prints a WARNING in the terminal and keeps going
  • Read the render output, not just the Word file
You see Fix
(magnuson?) The key doesn’t match refs.bib; check spelling and the bibliography: line
?@fig-ice_days The label and the reference must match exactly, and start with fig-
Code in the Word file Check the indentation of echo: false under execute:

5.12 Word and PDF from one render

format:
  docx: default
  typst:
    citeproc: true

quarto render paper.qmd now makes both paper.docx and paper.pdf.

  • default means “no extra options for this format”
  • Typst makes the PDF, with no LaTeX needed

Why citeproc: true?

  • Typst formats citations itself, and its APA output differs a little from Word’s
  • This tells it to use the same citation engine as the Word file
