3  Render and Publish

3.1 Two ways to share

Once your report renders, you can share it as:

  • a file: email it, post it on Canvas
  • a URL: publish it online

We will do both in this unit.

3.2 What render made

ls
data  report.html  report.qmd  report_files
  • report.html is the page
  • report_files/ holds the figure and the page’s styling

Email someone just report.html:

  • the figure and styling are missing

3.3 One self-contained file

Change format: in your YAML header:

---
title: "Ice Cover on Lake Mendota"
author: "Your Name"
date: today
format:
  html:
    embed-resources: true
---
  • html moves to its own line, indented under format:
  • YAML cares about indentation; use two spaces per level
  • embed-resources: true packs the figure and styling into the HTML file

3.4 Render again

quarto render report.qmd
ls
data  report.html  report.qmd
  • report_files/ is gone
  • report.html is now one file you can email or post
  • It is bigger (about 1.3 MB), because everything is inside it

3.5 Other formats, one flag

The same .qmd can become other formats:

quarto render report.qmd --to docx
quarto render report.qmd --to typst
  • docx: a Word document
  • typst: a PDF, with no LaTeX needed
  • More on Word output in the manuscript unit

3.6 Posit Connect Cloud

Posit Connect Cloud hosts documents online for free.

  • You made an account before the workshop

On the free plan, everything you publish is public:

  • Anyone with the link can see it
  • It is listed on your public profile page
  • This is true even if your GitHub repo is private
  • Never publish private or sensitive data

3.7 Publish

quarto publish posit-connect-cloud report.qmd

What happens:

  • Quarto renders the report on your computer
  • It uploads only the output
  • Connect Cloud never runs your code

3.8 First time only: authorize

Quarto first asks to Authorize:

  • Press Enter
  • Quarto prints an authorization code and opens your browser
  • Log in to Connect Cloud if asked, then approve the request

Quarto saves the authorization on your computer.

  • You will not need to do this again on this computer

3.9 Your report is live

When it finishes, Quarto prints the URL and opens it:

Published: https://connect.posit.cloud/your_name/content/...
  • Share this link with anyone
  • The title on Connect Cloud comes from title: in your YAML

The title is set only on the first publish.

  • To rename it later, use the Connect Cloud website

3.10 Update it

Change your report, then run the same command:

quarto publish posit-connect-cloud report.qmd

Quarto asks Publish update to:

  • The first choice is your report’s URL; press Enter
  • Don’t choose “Add a new destination”; that makes a second copy

How does Quarto remember the URL?

  • The first publish created _publish.yml next to your report
  • It records where report.qmd was published
  • Keep it, and don’t edit it

3.11 Your turn

ImportantTry it
  1. Add a sentence with the longest winter on record (Hint: max(ice$ice_days))
  2. Publish the update with quarto publish posit-connect-cloud report.qmd
  3. Reload your report’s URL and find your new sentence

We have:

  • Rendered the report to one self-contained HTML file
  • Seen that one flag switches the output to Word or PDF
  • Published the report to Posit Connect Cloud
  • Updated it at the same URL
